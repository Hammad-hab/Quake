Installation            1. make a directory under quake called "ATF"
                        2. Unzip the zip file to that directory.
                        3. Run quake with
                        quake -game atf -winmem 12
                        (or higher thatn 12 if you want)
                        4. Select Any mode of play you want.
                        the Start map has been replaced so you can go
                        from there, or go to the maps by name..they are

                        start
                        atfe1m1, atfe1m2, atfe1m3, atfdm1,
                        atfe2m1, atfe2m2, atfe2m3, atfdm2,
                        atfe4m1, atfe4m2, atfe4m3, atfe4m4, 
                        atfe5m1, atfe5m2.
                        


No extra impulses have been inluced so there is no need to bind keys
or anything annoying like that. Just use your normal quake config and
go kick some butt!
